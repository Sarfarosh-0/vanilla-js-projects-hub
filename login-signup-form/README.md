# Login & Signup Form

A responsive authentication form template with dynamic tab switching and real-time input validation.

## What it does
- Allows toggling between Login and Signup modes smoothly without page reload.
- Validates user input in real-time (email format, minimum password length, and password confirmation match).
- Displays clear error or success indicators next to individual fields.
- Intercepts default form submission to handle validation client-side.

## How to use
1. Open `index.html` in your browser.
2. Switch between Login and Signup tabs.
3. Fill in the fields and note the real-time validation feedback.
4. Attempt to submit with valid or invalid fields to test the handler.

## Concepts practiced
- Regular expressions for email format validation
- Handling form events (`input`, `blur`, `submit` with `preventDefault()`)
- Dynamic DOM class updates to show/hide error messages
- Tab state toggling

## What I learned
I learned how to construct regular expressions for practical form validation and how to design user feedback that guides users without being intrusive.
