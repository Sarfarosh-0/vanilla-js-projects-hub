# Color Flipper

A simple color flipper that changes the page background color dynamically using presets or random hex generators.

## What it does
- Changes the background color of the page when clicking the button.
- Displays the current hex code or color name directly on screen.
- Allows copying or viewing the generated color value.

## How to use
1. Open `index.html` in your browser.
2. Click the "Flip Color" button.
3. Observe the background change and read the updated color code.

## Concepts practiced
- `Math.random()` and `Math.floor()` for index or character picking
- Manipulating element inline styles via `document.body.style.backgroundColor`
- DOM selection and text updates with `textContent`

## What I learned
This project helped solidify generating random numbers within specific bounds and translating those numbers into valid 6-character hex color codes.
