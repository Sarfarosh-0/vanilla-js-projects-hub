## 3. Reddit Post (r/learnprogramming or r/webdev)

*Note: Check individual subreddit rules regarding showcase/self-promotion days (e.g., Showoff Saturday).*

**Title:** I built an open-source hub for beginners to practice their first GitHub PRs using vanilla JavaScript

```markdown
Hi everyone!

When I was first learning Git and GitHub, opening my first Pull Request felt intimidating. Most popular open source repos have large mono-repos, complex CI/CD pipelines, or framework dependencies that can easily overwhelm a beginner.

To help solve this, I built **Vanilla JS Projects Hub**:
**GitHub Repo:** https://github.com/Sarfarosh-0/vanilla-js-projects-hub

### What is it?
It's a curated hub of self-contained vanilla JavaScript projects (calculators, to-do apps, games, API consumers) built with pure HTML, CSS, and ES6+ JavaScript.

### How it works:
1. **Zero build steps:** Every project runs simply by opening `index.html` in your browser.
2. **Automated CI Validation:** A GitHub Action automatically validates folder structure, relative paths, and security rules on every PR to give immediate feedback.
3. **Contribution Ladder:** 
   - *Level 1:* Accessibility enhancements, documentation fixes, or adding screenshots.
   - *Level 2:* Bug fixes or small feature additions to existing apps.
   - *Level 3:* Adding a new vanilla JS project.
4. **Beginner Guide:** We wrote a detailed [First Contribution Guide](https://github.com/Sarfarosh-0/vanilla-js-projects-hub/blob/main/docs/first-contribution.md) that walks through forks, branches, and how to fix common beginner mistakes (like committing to main or dealing with merge conflicts).

I'm aiming to review every PR within 7 days and provide constructive, friendly feedback.

If you're looking for your first open-source contribution or have ideas for cool mini-projects to add, feel free to check out the repo and claim a `good first issue`!
```
