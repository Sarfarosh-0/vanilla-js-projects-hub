# Counter App

A classic click-counter application with visual color feedback based on the count value.

## What it does
- Increments, decrements, and resets a numeric counter.
- Dynamically shifts display colors: green when positive, red when negative, and neutral when zero.
- Retains smooth response to rapid clicking.

## How to use
1. Open `index.html` in your browser.
2. Click "Decrease" to reduce the counter value.
3. Click "Reset" to return the counter to zero.
4. Click "Increase" to increment the counter value.

## Concepts practiced
- Keeping simple numeric state in a JavaScript variable
- Conditional class toggling / color updates according to values
- Attaching click listeners to multiple action buttons

## What I learned
I learned the fundamentals of maintaining a single source of truth for component state and using conditional logic to mirror state changes in the UI.
