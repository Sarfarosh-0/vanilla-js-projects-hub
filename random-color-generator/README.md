# Random Color Generator

An interactive color generator that renders random background color schemes and presents their RGB/hex values.

## What it does
- Produces randomized color schemes on demand.
- Updates the viewport background dynamically.
- Presents the exact color representation so users can copy it.

## How to use
1. Open `index.html` in your browser.
2. Click the generate button to produce a new background color.
3. View the color string displayed on screen.

## Concepts practiced
- Generating random integers between 0 and 255 for RGB channels
- Event listener bindings and DOM property updates
- CSS transitions for smooth color switching

## What I learned
I learned how to construct RGB string templates in JavaScript and apply them across multiple DOM elements with clean transitions.
