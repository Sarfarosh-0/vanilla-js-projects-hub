# Rock Paper Scissors

The classic Rock, Paper, Scissors game played in your browser against a computer opponent.

## What it does
- Lets the player choose between Rock, Paper, or Scissors.
- Generates a randomized choice for the computer.
- Computes the winning rules (Rock beats Scissors, Scissors beats Paper, Paper beats Rock).
- Maintains live score counters for both Player and Computer across rounds.

## How to use
1. Open `index.html` in your browser.
2. Click any of the choice icons (Rock, Paper, or Scissors).
3. View the computer's selection and the round outcome announcement.
4. Keep playing to run up your win streak!

## Concepts practiced
- Array indexing and random choice selection
- Game rule logic with switch or nested conditional checks
- Live score state tracking and DOM text updates
- UI animation and feedback styling

## What I learned
This project helped me practice modeling game rules in clean conditional structures and handling asynchronous UI updates between player choice and round resolution.
