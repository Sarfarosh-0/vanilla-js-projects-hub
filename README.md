# 🚀 Vanilla JS Projects Hub

A curated collection of vanilla JavaScript projects built for beginners and developers to learn, build, and master open-source contributions.

No frameworks, no complex build steps—just pure **HTML5**, **CSS3 / Tailwind**, and **ES6+ JavaScript**.

---

## 🎯 Purpose of This Hub

1. **Learn by Building**: Explore real-world vanilla JavaScript projects ranging from beginner DOM widgets to intermediate stateful apps.
2. **Learn Open Source**: Practice the complete GitHub open source workflow—forking, branching, coding to specification, submitting PRs, and participating in code reviews.

## 🧗 Contribution Ladder

We welcome contributors of all experience levels! You can climb the ladder at your own pace:

- **Level 1 — Quick Fixes**: Fix typos, improve documentation, add accessibility tags, or submit screenshots.
- **Level 2 — Enhancements**: Fix bugs, add responsive touches, or introduce new features to existing projects.
- **Level 3 — New Project**: Build a brand-new vanilla JS project and add it to the hub!

Check out our [Contributing Guide](CONTRIBUTING.md) and [First Contribution Guide](docs/first-contribution.md) to get started!

## 🚀 Running Projects Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Sarfarosh-0/vanilla-js-projects-hub.git
   cd vanilla-js-projects-hub
   ```
2. Navigate into any project folder and open its `index.html` directly in your browser, or use a local dev server such as VS Code's Live Server.
3. *Note for projects requiring an API key (e.g. Weather App):* Set your key in the project's designated JS placeholder constant before running.
