# Basic To-Do App

A simple to-do list manager built with pure HTML, CSS, and vanilla JavaScript.

## What it does
- Allows users to enter tasks via an input field and add them to a list.
- Lets users mark tasks as completed by clicking on them.
- Provides a delete button to remove tasks immediately from the DOM.
- Validates input to prevent adding empty tasks.

## How to use
1. Open `index.html` in any modern web browser.
2. Type a task into the text input.
3. Click "Add" or hit Enter to append it to the list.
4. Click on a task item to toggle completion (strikethrough styling).
5. Click the trash icon / delete button next to a task to delete it.

## Concepts practiced
- DOM manipulation (`document.createElement`, `appendChild`, `removeChild`)
- Event delegation and click listeners
- String validation with `.trim()`
- Conditional class toggling for status updates

## What I learned
Building this project helped me understand the fundamentals of direct DOM manipulation and how event listeners interact with dynamically created elements without relying on any front-end frameworks.
