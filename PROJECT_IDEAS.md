# 💡 Project Ideas for Contributors

Looking for inspiration to build your first or next vanilla JavaScript project? Here is a curated list of project ideas categorized by difficulty level. 

Feel free to pick an idea, open an issue to claim it, and build it!

---

## 🟢 Beginner Ideas (Level 1–2)

1. **Pomodoro Timer**: 25-minute work and 5-minute break timer with audio chimes and start/pause/reset controls.
2. **Tip Calculator**: Computes tip percentage, custom split among people, and total bill per person.
3. **Word Counter / Character Counter**: Live typing statistics showing character count, word count, reading time, and sentence count.
4. **Markdown Previewer**: Two-panel view with raw text input on the left and rendered HTML on the right.
5. **Dice Roller / Coin Flipper**: Visual dice roller with 2D/3D CSS animations and history tracking.
6. **Drum Kit / Soundboard**: Interactive keys triggering audio playback on keyboard presses and clicks.
7. **Quote Generator**: Displays inspirational programming quotes with a button to copy or fetch new quotes.
8. **Accordion / FAQ Widget**: Smooth collapsible accordion menu for questions and answers.
9. **Flashcard App**: Flip cards to reveal vocabulary definitions or quiz answers.
10. **Analog Clock**: Clock with moving second, minute, and hour hands using CSS transform rotations.

---

## 🟡 Intermediate Ideas (Level 2–3)

1. **Memory Match Card Game**: Grid of face-down cards that flip when clicked; match identical pairs with timer and move counters.
2. **Kanban Task Board**: Multi-column board (To-Do, In Progress, Done) with HTML5 Drag-and-Drop API and localStorage persistence.
3. **Typing Speed Test (WPM)**: Real-time speed test tracking Words Per Minute (WPM), accuracy percentage, and highlighted typing errors.
4. **Drawing Canvas**: Sketchpad using the HTML5 `<canvas>` API with brush sizes, color picker, eraser, and PNG export.
5. **Recipe Finder**: Search recipes via a public API (e.g. TheMealDB) displaying ingredients, instructions, and thumbnail previews.
6. **Quiz Application**: Multi-question quiz with score tracking, timer countdown per question, and results breakdown.
7. **Audio Player / Visualizer**: Custom-designed audio player with seek slider, playlist management, and play/pause state.
8. **Habit Tracker**: Weekly habit grid tracking daily completions with progress bars stored in localStorage.
9. **Password Generator**: Configurable password generator with options for length, symbols, numbers, and uppercase characters plus a copy button.
10. **Currency Converter**: Real-time currency exchange calculator querying free exchange rate endpoints.

---

## 💡 Have Your Own Idea?

You aren't limited to this list! As long as it is built with vanilla HTML, CSS, and JavaScript (without build steps or frameworks) and follows our [rules](CONTRIBUTING.md), we welcome your creativity!
