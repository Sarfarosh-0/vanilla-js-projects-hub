# BMI Calculator

A responsive Body Mass Index (BMI) calculator with unit conversion and an interactive visual gauge.

## What it does
- Computes BMI values based on height and weight inputs.
- Supports both Metric (kg/cm) and Imperial (lbs, feet/inches) measurement units.
- Categorizes results into Underweight, Normal, Overweight, and Obese with visual color indicators.
- Automatically resets the form after 30 seconds of inactivity.

## How to use
1. Open `index.html` in your browser.
2. Select your preferred measurement unit.
3. Input your weight and height values.
4. Click "Calculate" to view your BMI score and health category.

## Concepts practiced
- Form handling and numerical input validation
- Parsing strings (feet/inches conversion)
- Mathematical calculations and rounding with `toFixed()`
- Dynamic CSS styling (conic gradient gauge and conditional category colors)
- Timers using `setTimeout` and `clearTimeout` for auto-reset

## What I learned
This project taught me how to handle multi-unit inputs cleanly and how to translate numerical computation into an intuitive visual gauge using CSS custom properties.
